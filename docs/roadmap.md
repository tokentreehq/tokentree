# TokenTree Public Roadmap

This roadmap outlines the planned development trajectory for TokenTree following the public-beta release.

---

## Current Status: Public Beta (v0.2.x)

- Rust-first local authoritative measurement engine.
- SQLite WAL ledger with transactional migrations.
- Streaming Claude Code fallback parser and OTLP loopback receiver.
- Truth-ladder deduplication and canonical request identities.
- Exact integer-micro cost arithmetic with cache-tier rates.
- Conservative CONTINUE / CHILD / SWITCH boundary classifier with 100% precision fixtures.
- Recursive project and work-item hierarchy with terminal tree rendering.
- Versioned attribution corrections (rename, move, add note, attach, detach) maintaining 10,000 basis points invariants.
- Local loopback web dashboard with ephemeral token authentication and strict CSP.
- Self-contained static HTML and multi-format (JSON, CSV) report exports.
- Non-destructive prototype migration with automatic backup.

---

## Milestone 1: Expanded Agent Adapters

- **OpenAI Codex**: Integration with the documented Codex app-server protocol and rollout event formats.
- **Community Adapter SDK**: Typed TypeScript and Rust interfaces for third-party agent builders.
- **Cursor & Copilot Exporters**: Parsers for local development logs and workspaces.

---

## Milestone 2: Pricing & Multi-Currency

- **Custom Enterprise Rate Tables**: Support for negotiated organization discount rates and custom currency exchange tables.
- **Automated Price Sync**: Cryptographically signed quarterly price updates with offline fallback.

---

## Milestone 3: Cross-Project Relationships & Team Aggregation

- **Cross-Project Links**: Support for `related_work_items` bridging shared libraries and consumer apps.
- **Privacy-Preserving Team Sync**: Opt-in zero-knowledge summaries for engineering teams without exposing local code paths or prompt metadata.
